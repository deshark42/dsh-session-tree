This plugin includes selected source files adapted from DeepSeek Harness, commit
`d743267388641bc76f17c45ce8b4c231aed1d32c`, with turn deletion support.
The Session surface, tool history, V4 validators,
and Turn footer originate from DeepSeek Harness, Copyright (c) 2026 DeepSeek,
licensed under MIT. The upstream copyright notice and license are retained in
[src/lib/vendor/LICENSE](src/lib/vendor/LICENSE).

The package contains the plugin and its compatibility library; it does not
bundle the complete dsh application. Installing the npm package does not edit
dsh's installed files.
